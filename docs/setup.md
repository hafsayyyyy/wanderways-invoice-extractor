# Setup Guide

## Requirements

Before running the project, make sure the following are installed:

- Python 3.x
- Git
- Visual Studio Code

## Installation

Clone the repository:

git clone https://github.com/hafsayyyyy/wanderways-invoice-extractor.git

Move into the project directory:

cd wanderways-invoice-extractor

## Install Dependencies

If a requirements.txt file is available, install the required packages:

pip install -r requirements.txt

## Running the Project

Run the main Python program from the src directory.

Example:

python src/main.py

## Sample Invoices

Sample travel invoice PDFs are available in the samples folder.

These files can be used to test the invoice extraction process.
